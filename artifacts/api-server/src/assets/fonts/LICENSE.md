# Fonts

Three faces, self-hosted so the landing page loads nothing from a third party.
Fetching them from Google's CDN would put every reader's IP address in front of
Google on a page that promises the opposite, and it would mean opening the
page's `style-src` and `font-src` to another origin. Serving them ourselves
costs 138 KB, cached for a year behind a content-hashed URL.

Each file is the **latin subset** of the family's variable font, exactly as
served by `fonts.googleapis.com/css2` for the weights the page uses — one file
per family, covering every weight, because the axis is continuous.

| File | Family | Axes used | Source |
|---|---|---|---|
| `bricolage-grotesque-latin.woff2` | Bricolage Grotesque | wght 500 / 600 / 800 | https://github.com/ateliertriay/bricolage |
| `instrument-sans-latin.woff2` | Instrument Sans | wght 400 / 500 / 600 | https://github.com/Instrument/instrument-sans |
| `jetbrains-mono-latin.woff2` | JetBrains Mono | wght 400 / 500 / 700 | https://github.com/JetBrains/JetBrainsMono |

All three are under the **SIL Open Font License 1.1**, which permits
redistribution — including bundling with software and serving over the web —
provided the licence travels with the font. It does: the full text of each is
below, verbatim from the upstream project.

The app uses the same three families through `@expo-google-fonts`, so the page
and the product are typographically one thing.
